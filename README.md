# Calculadora jQuery

Este é um projeto simples de calculadora desenvolvido utilizando apenas HTML, CSS e jQuery, sem frameworks adicionais de JavaScript.

# Descrição

O objetivo deste projeto é criar uma calculadora funcional que permita realizar operações matemáticas básicas, como:

Adição
Subtração
Multiplicação
Divisão

A interface é interativa e responsiva, e toda a lógica da calculadora é implementada no jQuery, demonstrando manipulação de eventos, atualização de elementos DOM e controle de entradas do usuário.

#Funcionalidades

Realiza operações básicas (+, -, ×, ÷)
Interface intuitiva e simples
Suporte para múltiplos dígitos e números decimais
Limpeza do display (botão "C")

# Tecnologias utilizadas

HTML5 <br>
CSS3 <br>
jQuery
